# Phoenix Trading Platform

## Overview

Phoenix Trading Platform is an automated options trading system built for the Dhan API.

The platform is designed to execute the proprietary Phoenix Strategy based on KS Levels.

## Technology Stack

- Python 3.12
- Dhan API
- TradingView
- SQLite
- Loguru
